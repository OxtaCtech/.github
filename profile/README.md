# OxtaCtech

**Engineering excellence. Evidence before approval.**

OxtaCtech develops, evaluates and validates cutting-edge software and infrastructure technologies with an emphasis on reliability, security, reproducibility and responsible engineering.

## How we work

We treat **implementation, verification and homologation** as separate steps:

- Design and acceptance criteria are recorded before implementation.
- Reviews, tests and security checks provide reproducible evidence.
- Claims about reliability or competitive performance require relevant baselines.
- Failed experiments and rejected changes are documented, not hidden.
- A passing build or merged Pull Request does not equal production approval.

## Engineering standards

The [Engineering & Validation](https://github.com/orgs/OxtaCtech/projects/1) and [Research & Benchmarking](https://github.com/orgs/OxtaCtech/projects/2) templates define reusable processes.
